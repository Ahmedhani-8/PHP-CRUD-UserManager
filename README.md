# PHP CRUD User Manager

Simple **PHP/MySQL** CRUD application for managing users (create, read, update, delete) with Dockerized setup.

---

## Project Overview

- Manage a list of users (first name, last name, email, gender).
- Supports adding, editing, and deleting users.
- Uses a MySQL database with a single table `crud`.

---

## Tech Stack

- PHP 8.2 + Apache
- MySQL (XAMPP on host)
- Bootstrap 5 + Font Awesome
- Docker
